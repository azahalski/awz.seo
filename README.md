# AWZ: SEO

Модуль Bitrix CMS для управления SEO-инструментами сайта: редиректы, canonical-теги, meta-теги и система прав доступа.

## Detailed Description

Модуль **AWZ: SEO** предназначен для оптимизации поисковых параметров сайта на платформе 1C-Bitrix. Он предоставляет комплексный набор инструментов для управления редиректами, canonical-тегами, meta-тегами и системой прав доступа.

### Основные возможности

#### SEO-редиректы (обработка на событии `OnPageStart`)

Модуль поддерживает несколько типов редиректов с защитой от зацикливания (цепочка ограничена 5 шагами):

- **Редирект с множества слешей на один** — например, `https://site//path///to///page` → `https://site/path/to/page`
- **Редирект без слеша на со слешем** — например, `/path` → `/path/`. Слеш добавляется перед GET-параметрами: `/path?a=b` → `/path/?a=b`. URL с расширениями файлов (.html, .php и т.п.) не затрагиваются
- **Редирект с http на https** — все http-запросы перенаправляются на https с сохранением пути и GET-параметров
- **Редирект с index.php на слеш** — например, `/index.php` → `/`, `/path/index.php` → `/path/`. GET-параметры сохраняются: `/index.php?a=b` → `/?a=b`
- **Редирект www / без www** — перенаправление между версиями хоста с www и без www. Можно выбрать только одно направление (или выключить) — это исключает зацикливание редиректов
- **Кастомные редиректы (CSV)** — пары «старый URL, новый URL» из CSV-файла. Обрабатываются с приоритетом над остальными редиректами

Настройка кода ответа редиректа: 301 (постоянный) или 302 (временный).

#### Canonical-теги (обработка на событии `OnEpilog`)

Гибкая настройка тега `<link rel="canonical">`:

- **Режимы вывода**: выключен, добавлять всегда для текущей страницы, добавлять только если есть GET-параметры
- **Страницы пагинации не канонические** — из canonical исключаются параметры пагинации `PAGEN_N`: `/catalog/?PAGEN_1=2` → canonical на `/catalog/`
- **Исключать GET-параметры из canonical** — canonical указывает на чистый URL страницы без query-строки (кроме параметров из списка исключений)
- **Canonical всегда с https** — в теге canonical схема https используется независимо от схемы текущего запроса
- **Заменять index.php на слеш в canonical** — `/index.php` → `https://site/`, `/path/index.php` → `https://site/path/`
- **Не выводить canonical на страницах ошибок** — для страниц с кодом ответа 4xx/5xx (404 и др.) тег canonical не выводится
- **Перезаписывать существующий canonical** — при выключенной опции модуль не переопределяет canonical, установленный выше по коду (компонентами или шаблоном сайта)
- **Сохранять GET-параметры в canonical** — список параметров через запятую (например: `utm_source,utm_medium`), действуют при включённом исключении GET-параметров
- **Правила preg_replace для canonical** — множественные правила from → to, применяются к итоговому canonical URL по порядку. From — полное регулярное выражение с ограничителями, To — замена

#### Meta-теги (обработка на событии `OnEpilog`)

Управление meta-тегами и пометкой страниц пагинации:

- **Очищать meta keywords** — устанавливает тег `meta name="keywords"` пустым на всех страницах сайта
- **Метка страницы пагинации** — на страницах пагинации (параметры `PAGEN_N`) добавляет номер страницы в title, description и заголовок страницы по шаблонам с макросом `#PAGE#`
  - Настройка номера страницы, начиная с которой добавлять метку (по умолчанию со 2-й)
  - Шаблон для `title` (`$APPLICATION->SetTitle`)
  - Шаблон для `meta description`
  - Шаблон для заголовка страницы (`PAGE_TITLE`, обычно используется в H1)

## Options and Configuration

Все настройки модуля хранятся раздельно для каждого сайта (многосайтовость) с использованием `\Bitrix\Main\Config\Option`.

### Общие настройки

| Опция | Описание |
|-------|----------|
| `SITE_ID` | Выбор сайта для настройки |
| Права доступа | Настройка прав для просмотра и редактирования настроек модуля |

### Настройки редиректов

| Опция | Описание |
|-------|----------|
| `REDIRECT_MULTI_SLASH` | Редирект с множества слешей на один (`Y`/`N`) |
| `REDIRECT_SLASH_END` | Редирект без слеша на со слешем (`Y`/`N`) |
| `REDIRECT_HTTPS` | Редирект с http на https (`Y`/`N`) |
| `REDIRECT_INDEX_SLASH` | Редирект с index.php на слеш (`Y`/`N`) |
| `REDIRECT_CODE` | Код ответа: `301` (постоянный) или `302` (временный) |
| `REDIRECT_WWW` | Редирект www: `N` (выключен), `W` (www→без www), `NW` (без www→www) |
| `REDIRECT_CUSTOM_PATH` | Путь к CSV-файлу с кастомными редиректами |

### Настройки canonical

| Опция | Описание |
|-------|----------|
| `CANONICAL_MODE` | Режим: `N` (выключен), `A` (всегда), `G` (только с GET) |
| `CANONICAL_PAGEN_NONCANONICAL` | Страницы пагинации не канонические (`Y`/`N`) |
| `CANONICAL_STRIP_GET` | Исключать GET-параметры из canonical (`Y`/`N`) |
| `CANONICAL_KEEP_GET` | Список GET-параметров для сохранения через запятую |
| `CANONICAL_HTTPS` | Canonical всегда с https (`Y`/`N`) |
| `CANONICAL_INDEX_SLASH` | Заменять index.php на слеш (`Y`/`N`) |
| `CANONICAL_SKIP_ERRORS` | Не выводить canonical на страницах ошибок (`Y`/`N`) |
| `CANONICAL_OVERRIDE` | Перезаписывать существующий canonical (`Y`/`N`) |
| `CANONICAL_REGEX` | Правила preg_replace для canonical (сериализованный массив) |

### Настройки meta

| Опция | Описание |
|-------|----------|
| `META_KEYWORDS_CLEAN` | Очищать meta keywords (`Y`/`N`) |
| `META_PAGEN_ENABLE` | Включить обработку страниц пагинации (`Y`/`N`) |
| `META_PAGEN_FROM` | Номер страницы, начиная с которой добавлять метку |
| `META_PAGEN_TITLE_TEMPLATE` | Шаблон для title (макрос `#PAGE#`) |
| `META_PAGEN_DESCRIPTION_TEMPLATE` | Шаблон для description (макрос `#PAGE#`) |
| `META_PAGEN_PAGE_TITLE_TEMPLATE` | Шаблон для заголовка страницы (макрос `#PAGE#`) |

### Проверка настроек

Модуль предоставляет возможность отправить текущие настройки сайта во внешний сервис для получения отчёта о проверке редиректов и canonical.
